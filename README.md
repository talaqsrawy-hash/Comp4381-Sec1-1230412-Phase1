# Titanic Survival Analysis

## Project Description

This project explores the Titanic dataset to understand which factors may have affected passengers' chances of survival. It looks at the data, asks questions, and finds patterns that may explain why some passengers survived while others did not.

## Project Objectives

The main goal of this project is to understand how passenger information is related to survival.

During the analysis, we will try to answer questions such as:

- Did gender affect the chances of survival?
- Did children have a better chance of survival than adults?
- Did first-class passengers have a higher survival rate than second- and third-class passengers?
- Was ticket price related to survival?
- Did passengers traveling with their families have different survival rates?
- Did the passenger's port of embarkation affect their chances of survival?
- Which passenger details were most related to survival?

By answering these questions, we hope to find patterns in the data and understand which factors had the strongest connection to survival.

## Dataset

The dataset is taken from the instructor's GitHub repository:

[Data Science Projects – Titanic Survival Prediction](https://github.com/asabbah44/Data-Science-Projects/tree/main/Titanic%20Survival%20Prediction)

The dataset has two CSV files:

- `titanic_train.csv`: Contains passenger information and survival results. This will be the main file used in our analysis.
- `titanic_test.csv`: Contains passenger information that can also be used to explore the data.
